Embedded Framework

EF Launch Pad

Use this page to establish a top-level Genesys Cloud session first, then open the local Embedded Framework host page. This is the cleanest available test flow for Azure-backed SSO with the local EF example.

Step 1: Login to Genesys Cloud

Open Genesys Cloud in a top-level window or tab and complete the Azure SSO flow there. Do not skip this step. The goal is to establish the Genesys session before EF loads.

Open Genesys Cloud

Step 2: Open Embedded Framework

After the Genesys Cloud session is active in the same browser profile, open the local EF host page.

Open Embedded Framework

If EF still prompts for Azure login after Step 1, then the existing Genesys session is not being reused by the embedded flow.
